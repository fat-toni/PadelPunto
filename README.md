# Padel Punto

Padel score counter for Amazfit watches with Zepp OS: one tap per point, spoken score, Golden
Point and Star Point. Free, no ads, no data collection. You find it in the Zepp App Store (Zepp
app → Profile → your watch → App Store → "Padel Punto").

- **Privacy policy:** [PRIVACY.md](PRIVACY.md)
- **Feedback and bug reports:** [open an issue](https://github.com/fat-toni/PadelPunto/issues),
  in English, German or Spanish
